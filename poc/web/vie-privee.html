Niveau de partage de vos demandes

Aperçu pour les autres

Chaque changement se confirme avec votre clé d'accès. Les demandes de santé restent toujours discrètes pour les autres. Vous voyez toujours vos propres demandes en entier.

Conservation

Le journal garde vos demandes 30 jours. Le son n'est jamais conservé.

Passé ce délai, les entrées disparaissent seules. Vous pouvez aussi effacer les vôtres tout de suite, sans toucher à celles des autres.

Effacer vos entrées ?

Toutes vos demandes disparaissent du journal, pour vous comme pour les autres. Cela ne se défait pas.
